kittens

Um pet em pixel art que mora dentro de qualquer div. Ele anda, corre, pula nos seus elementos e escala as paredes, brinca, se limpa e tira soneca por conta própria. Clique nele, deixe o mouse parado em cima para fazer carinho, arraste para pegá-lo no colo — ou dê dois cliques em qualquer canto do palco para chamar os gatos até lá. Abrir o playground

Eventos

    Como usar

    Como Web Component, dentro do elemento em que ele deve morar:

    <section class="minha-area">
  …seus elementos…
  <kitten-pet coat="calico" scale="3" name="Mingau"></kitten-pet>
</section>

    Ou pela API em TypeScript:

    import { Kitten } from 'kittens';

const gato = new Kitten(document.querySelector('#area')!, {
  coat: 'laranja',
  behaviors: { nap: 2, explore: 0 },
});
gato.addEventListener('statechange', (e) => console.log(e.detail.state));
gato.do('sleep');
